# 模拟审批、问答与示例交付（2026-11-14）

本功能用于本地产品验收，不调用真实模型、不运行项目代码、不读取或修改业务项目文件。示例文档只保存在控制库，始终标注“模拟”，不能作为真实项目结论。

## 启动

先按 worker-integration.md 创建测试账号、项目并注册对应租户的 Worker。不要为队列 Worker 手工占用诊断租约，调度器会自动分配。

在 services/product-api 目录使用同一控制库：

```sh
PRODUCT_API_DB=./control-data/product.sqlite PRODUCT_API_SIMULATE=1 PRODUCT_API_SIMULATION_FLOW=1 node server.mjs
```

两个标志均显式开启才让新任务使用交互流程。只开启 SIMULATE 的简单回显模式仍保留。消息接收和运行记录都保存交互模式；之后关闭 FLOW 不会将已经指定交互流程的任务降级成自动回显。

## 用户流程

1. 在独立网页打开项目，发送想法。
2. 看到“允许生成示例文档吗”，选择“允许一次”才会继续。拒绝会取消任务，不生成文档。
3. 回答服务对象和示例类型两道问题，再点“提交全部回答”。无效或漏答不会代填。
4. 我的成果出现“模拟交付示例.md”。点击阅读后，可自行决定“确认这一版”或“下载”。生成、阅读、下载都不自动确认。
5. 排队或等待回答时可点“取消模拟任务”；待决卡移除，旧回答失效。正在生成或已经完成时不会提供不安全的取消入口；接口也会拒绝。

状态优先显示正在运行、等待回答或待核对的任务，避免新排队消息覆盖当前等待的任务。

## 状态与恢复

schema v5 新增模拟流程、数据库示例文档及持久模式字段；自动兼容原有数据。

- 许可、问题 ID 与阶段同事务保存。重复 tick 不会重复创建卡片。
- 用户等待阶段释放执行循环，但保留有效租约；交互租约默认五分钟，无自动续期。
- 已保存问题卡但等待状态确认丢失时，可在租约仍有效的条件下恢复原卡，不自动批准或作答。
- 示例正文、索引、未确认状态和完成回执同事务保存。完成回执丢失后只核对已有回执，不重复生成或确认。
- 租约过期、撤销或结果无法确定则进入待核对，撤销待决卡；不自动重新执行。
- 取消与恢复竞争时，事务内复核操作和租约状态，不能重新激活已取消任务。
- 下载和阅读沿用账号→租户→项目→成果归属检查，正文按 SHA-256 校验；数据库正文独立于真实文件工作区。

可在停止自动服务后使用同库的 PRODUCT_API_SIMULATE=1 node simulate.mjs --recover 核对已有记录。不要删除回执或手工将 uncertain 改回 queued。

## 验证

74 项离线回归，包含实际本地 HTTP 的许可、问答、阅读、hash 确认和下载；拒绝、排队/许可/问答阶段取消、过期、恢复竞争、配置变更及数据库重开。

隔离 Chrome 真实操作通过：允许一次→回答→阅读→明确确认→实际文件下载→取消下一任务；桌面和 390px 截图入主手册。使用虚构项目，无模型调用。数据库重开和确认丢失属于故障注入，不等同于服务器崩溃或真实 DSH 恢复演练。
