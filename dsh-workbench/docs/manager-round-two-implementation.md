## 参考案例与适配判断

核对了上游实际文档，未执行上游文档中的命令或安装其Agent框架：

- [GitHub Spec Kit specify](https://github.com/github/spec-kit/blob/main/templates/commands/specify.md)：从自然语言描述形成规格，以合理默认值处理一般空缺，限制需澄清项。采用“先形成可编辑方案、有限关键缺口”的思路。
- [Spec Kit clarify](https://github.com/github/spec-kit/blob/main/templates/commands/clarify.md)：按功能、数据、交互等维度检查歧义，并限制关键提问。采用覆盖维度和问题预算，未照搬其逐题终端交互。
- [BMAD requirements](https://github.com/bmad-code-org/BMAD-METHOD/blob/main/docs/plan/define-requirements-and-a-specification.md)：Fast path集中剩余缺口、形成全文并显式标注假设。结合普通用户场景采用“少量选项＋补充”，而非强制逐章访谈。

这是本项目的适配设计，不表示引入完整Spec Kit或BMAD运行时。策略要求覆盖FR/NFR/AC、流程、角色、边界、假设、风险及MVP建议；只有初步想法也能提出整理需求草案的建议。没有真实模型评测，因此不能保证每次都能生成充分的领域方案。

## 关键实现与边界

- `WorkspaceProvider` 在路径变化时清空普通聊天草稿，退出成功后清空项目/问答/发送状态；仍保留发送结果不确定时的历史核对语义。销户/删除数据未实现。
- `SourcesDialog` 区分只读参考与可修改副本。导入接口核验会话/Origin/CSRF、项目归属、资料SHA、大小与活动状态；仅从当前项目已校验的文字资料创建 `imported-project`，不接收浏览器本机绝对路径。不覆盖修改过的副本，不运行用户本机代码，不保证缺失的依赖/二进制可用。
- `ResizableInput` 使用上沿手柄；视口变化会收敛最大高度，且支持方向键/Home/End。许可待处理时替换整个普通输入区；拒绝、失效或结束后刷新恢复。问题批次一次提交，提交期间不可编辑。
- 深度流程通过共享内核answer-batch一次保存最新问题组，复用revision与requestId，幂等重放不新增续接任务；界面将问题块投影为集中表单，旧单题入口兼容保留。
- 单执行中的提问工具兼容旧单题输入，但首选结构化问题、选项与自由补充；问题总额最多3项。核心管家的对话JSON仍保持最多2个问题，不新增未经确认的自动执行。
- 网络工具默认关闭，可信Worker配置 `network.enabled=true` 才提供声明。命令容器继续完全无网络；不是任意网络shell或透明代理。仅公网HTTPS/443，验证DNS所有地址并将连接固定到已校验IP；重定向逐跳校验，拒绝内网/云元数据、保留地址、凭据URL及自定义认证头。读取不传客户Cookie或模型授权。
- 搜索结果最多6条，仅用作选页；读取成功才登记来源。一次执行最多6次网络操作，网页响应512KiB、正文16000字符、15秒超时、最多3次重定向。网页内容是不可信资料，不能改变执行权限。
- 固定依赖包仅允许 registry.npmjs.org / files.pythonhosted.org；所有跳转仍检查允许源，需可信SHA-256或npm SHA-512完整性摘要。单包16MiB，每项目64份/64MiB；仅下载校验，不解包、安装、运行或递归解决全部间接依赖。Linux用目录文件描述符锚定保存路径，拒绝符号链接目录；无后台自动清理。
- 来源（最多6项）作为Worker v1完成回执的可选字段，沿用签名、租约、序列及幂等规则。API投影到项目消息，共享管家按任务board关联，文件原稿也追加实际读取依据。链接、读取日期与SHA可追溯，不代表事实已经被独立证实。
- 陪学只允许公开只读检索与提问，命令/依赖下载许可仍拒绝。网络异常以失败结果返回，不重试同一次模型POST、搜索或下载，不生成成功引用。
