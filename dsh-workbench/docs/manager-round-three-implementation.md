# 第三轮实施记录

日期：2026-11-17（Asia/Shanghai）。范围：R3-01陪学领域知识补充、R3-02独立网页公式排版。当前完成本地实现与验证，远程推送/服务器切换以发布记录为准。

## 陪学链路

- 共享 LEARNING_POLICY 替换计划/答疑/资料整理中禁止所有工具、只总结文档的旧限制。项目事实与领域知识仍分开，项目知识地图继续只从项目资料抽取。
- 正式执行从服务端持久消息/共享会话推导受签名保护的 learning.action/research 元数据；创建计划、学习课程及明确请求学习资料/测试题时，网络启用后先要求搜索工具，再要求阅读返回来源。HTTP网关保留合法必选工具指令，同时过滤命令和下载工具。
- 每次搜索/读取仍申请独立许可，不自动批准。拒绝、无结果、故障或网络关闭时附“初步版本”说明；搜索摘要不形成来源回执。不改变6次网络操作/8次模型调用的原上限或模型凭据与预算。
- W编号只从正式来源回执生成，贯通普通学习计划、共享内核计划和新版课程卡；上传资料继续用原来源编号。修复无文档时学习提示未进入Worker的条件错误。
- 课程保存资料提示及原创题/答案/解析；答案默认折叠，普通和深度陪学共用LessonMaterials。共享学习资料导出包含课程提示、实际资料和题目解析。
- 短计划与逐单元讲解减少超长交付，但未实现自动续写、静默重试或保证所有长回复不触发原输出限制。

## 数学渲染

- 独立Next页面使用锁定版本KaTeX 0.19.1，CSS和字体随构建打包，不依赖CDN。官方配置与安全依据：[Options](https://katex.org/docs/options)、[API](https://katex.org/docs/api)。
- 统一Markdown分词保护代码、链接、普通URL和金额；处理美元、双美元、圆括号与方括号四种常见数学分隔符，兼容多行矩阵和Greek Unicode。
- 渲染输出HTML+MathML，trust=false、每式独立宏、maxExpand=200、maxSize=10，每式最多6000字符、每次最多64式；非法公式回退到React转义源码，公式指令不加载远程资源。
- 公式内局部横向滚动，复制保留源码；未闭合流式片段保留文字，闭合后重新渲染。对话、普通/深度课程及成果预览共用组件。
- 原插件前端、离线学习包和原DOCX/PDF/PPTX导出器没有改成原生数学排版；该边界在客户手册明示，不能把网页渲染当作所有格式验收。
