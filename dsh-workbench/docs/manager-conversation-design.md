# 简洁模式：以对话为主的交互调整

适用版本：1.18.0，2026-11-13。用户反馈：原简洁模式仍像表单，缺少自然对话感。本次在现有管家之上调整呈现，不更换执行系统。

## 参考及取舍

- [assistant-ui 对话示例](https://github.com/assistant-ui/assistant-ui/blob/main/apps/docs/components/pages/examples/chatgpt.tsx)：参考空白会话的自然开场、对话与稳定输入区、主动返回最新位置、运行时停止入口。这里保留现有 React 和 Host 接口，没有引入它的运行时或复制其代码。
- [LibreChat Artifacts](https://github.com/LibreChat-AI/docs/blob/main/content/docs/features/artifacts.mdx)：参考聊天与可持续修改的成果分开呈现。这里保留已有完整文档阅读面板及认证下载，暂未实现桌面并排编辑、实时协同或任意网页执行。

以上是交互参考，不是这些项目为本产品提供的兼容或可用性保证。

## 当前行为

1. 首屏只请用户说一句想法，名称折叠为可选项；示例填入草稿，用户继续编辑。下一次询问明确的成果范围，最后仍需确认约定。
2. 管家消息使用通透正文，用户消息使用轻量气泡。当前问题和执行建议接在对话末尾，不再与聊天分占两个区域。
3. 选项问题默认只展示选项；“我有其他回答”展开自由输入。无选项问题直接提供输入。
4. 单一对话滚动区域，输入区固定。用户翻旧消息时不强制追随；“回到最新进展”主动恢复跟随。顶部保留当前成果类别、状态及成果入口。
5. 阅读面板保留独立挂载、未提交评论和明确版本确认。把评论交给管家时关闭面板，聚焦已填入意见的聊天框；检查后由用户发送。
6. 运行中的停止入口留在底部；原生授权详情、错误恢复和全部执行校验继续使用现有机制。

## 验证边界

166 项测试覆盖原有执行和审阅校验，并增加不抢旧消息滚动位置、明确返回最新、自由回答入口及示例不自动执行。隔离虚构项目检查桌面、390px 窄屏、模式切换、审阅往返及运行入口；未调用真实模型，未开展普通用户真人试用。

新手手册及截图以 [manager-user-guide.md](manager-user-guide.md) 为准。下一轮建议由用户安排真实试用，记录是否能不经指导找到下一步、提出修改并下载文件。
