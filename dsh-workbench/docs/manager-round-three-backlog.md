# 管家第三轮修改清单

日期：2026-11-17（Asia/Shanghai）。
状态：**已获授权实施，已完成本地实现与验证，待提交推送和服务器发布**。实现与边界见[第三轮实施记录](manager-round-three-implementation.md)。

## R3-01 陪学主动补充领域知识

建议优先级：P1，待整轮排序。来源：用户试用反馈；尚未复现具体会话，根因待核对。

### 场景与问题

用户在“陪我学习”中提供文档，要求制定学习计划并提供对应学习资料与测试题。当前管家只总结上传文档，没有主动检索相关领域的专业知识，学习内容受原文覆盖范围限制。

### 预期交互与交付（待实施）

1. 分析学习目标、文档内容、必要前置知识和知识缺口；采用明确的合理假设，仅集中询问会影响安排的关键问题。
2. 主动判断需要补充的领域知识，说明检索主题并请求现有联网授权，无需用户反复提醒“上网查”。保留逐次授权，不自动批准。
3. 优先检索并实际阅读官方文档、标准、可靠教材、课程发布者及原始论文等资料，核对相关性与时效性。不能只凭搜索摘要或模型记忆声称完成联网。
4. 融合上传文档与外部知识，区分文档事实、领域通用知识和解释/推断；不把通用知识冒充当前项目的真实实现。
5. 学习计划明确阶段、目标、顺序、前置知识、建议时长与完成标准；每个单元配套通俗讲解、项目联系、参考资料、测试题、答案及解析。题目和答案分开展示，便于先作答，并根据反馈建议复习。
6. 关键外部知识与学习资料标注实际读取的来源标题、链接和读取信息；用户文档标注文件依据，适用时附页码或行号。原创测试题明确说明，不伪称出自教材或考试。
7. 联网被拒绝、不可用或找不到可靠来源时，说明缺口，可先交付资料内的初步方案；不得伪造引用。长篇计划、讲义和题库按单元组织，避免输出截断，不静默重试或重复收费。

### 验收标准（待实施后验证）

- 用一份只覆盖部分概念的虚构文档请求“学习计划＋资料＋测试题”，能识别知识缺口并主动提出检索授权。
- 授权后有真实检索、读取证据，方案补充相关专业知识，而非仅重述原文；来源可回溯。
- 每个单元的目标、讲解、资料与测试题对应，题目具有答案和解析，文档事实与外部知识可辨。
- 拒绝授权或网络失败时有明确反馈，不伪造成功、不无限等待、不自动重试。
- 长内容按单元交付，不将截断内容标记为完整学习方案。
- 实施时同步客户手册、离线版和受影响的真实截图。

### 待核对的实现环节

陪学路由是否获得检索工具、学习编排是否要求补充知识、授权入口是否可达，以及工具次数和输出长度限制。以上仅为排查方向，不能据用户反馈直接断言技术根因。

## R3-02 专业公式与中英文混排渲染

建议优先级：P1，待整轮排序。来源：用户试用反馈；具体异常样例及技术根因待实施前核对。

### 场景与问题

管家在对话、陪学讲解或测试题中输出数学公式、英文专业符号及希腊字母时，出现格式异常或直接显示公式标记，缺少专业排版，影响理解。

### 预期效果与建议方向（待实施）

- 支持行内和独立公式，识别常用LaTeX数学分隔符：单美元、双美元、反斜杠圆括号及方括号；正确显示分式、根号、上下标、求和、积分、矩阵及多行推导。
- 正确显示Unicode和公式命令中的希腊字母，区分英文正文、变量、函数名、单位与代码；不能把所有英文或美元金额误判为公式，也不能改写代码块、链接和文件路径。
- 中英文与公式混排时基线、行距、字体协调；长公式在自身区域滚动或适当换行，手机端不撑破整个页面。
- 流式输出尚未形成完整公式时保持稳定的临时文本，公式闭合后再渲染；不能因半截命令导致页面报错、闪烁或内容丢失。
- 无法解析的公式保留可读原文并给出适度提示，不静默删除、不让整条回答渲染失败。数学排版正确不等于数学结论已验证。
- 评估KaTeX或MathJax与现有Markdown组件的统一集成，字体和样式随应用提供；维持HTML与链接安全处理，不开放任意脚本或远程资源加载。具体库与版本在实施时核对。
- 对话、学习资料与成果预览使用一致的公式规则；复制时尽量保留可复用的公式源码。核对离线HTML及PDF/Word等交付渠道，逐项说明支持范围，不把网页渲染成功等同于全部导出已支持。

### 验收标准（待实施后验证）

- 虚构示例覆盖勾股公式、分式、根号、积分/求和、矩阵、多行公式，以及alpha、beta、theta等命令和对应Unicode字母。
- 同一回答中混排中文、英文、公式、金额和代码，语义与格式均保留，代码及非数学内容不会被错误转换。
- 桌面及手机页面无横向整体溢出、遮挡或公式裁切；长公式可完整查看。
- 模拟流式分片在分隔符、转义字符和命令中途切开，最终显示正确且无未捕获异常。
- 无效或不支持的表达式能回退，历史消息刷新后仍能正确显示；页面渲染不执行不可信脚本。
- 覆盖对话、陪学、成果预览及实际支持的交付格式，注明尚未支持的渠道；同步手册、离线版和受影响真实截图。
