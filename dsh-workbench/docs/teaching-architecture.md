# 项目陪学教学优化：实现与续接记录

版本 1.24.0，分支 personal_manager。三个批次完成；真实模型与真人教学效果待独立验收。部署暂停，不更新服务器或推送远程。

## 第一批：教学循环与学员观察（完成）

learning-coach.js 以服务端状态机控制 diagnostic / explain / practice / feedback / transfer / review；可跳过、暂停、续学及按需提示。普通答疑与步骤作答分开。模型不能自行调用开发操作或推进状态。理解反馈与讲解共用一次模型请求，观察字段需结构化且原话存在于本次用户回答；检查只验证文字依据，不证明语义判断正确。观察有 tentative / supported 标签，用户可纠正；纠正后的误区不再注入提示词。

教学输入只使用用户选择的项目资料，既有无工具 preset 不变。旧项目默认无 coach / observations，按需创建；阅读和用户自评状态仍独立。过程、观察及原话证据随 manager.json 保存，重复操作和重启恢复沿用现有监督机制。

## 第二批：项目知识关联与学习记忆（完成）

从允许范围内的资料生成有来源的功能—概念—前置关系；以用户熟悉的产品功能进入学习，推荐相关资料但仍由用户确认范围。按概念及当前问题检索旧观察与归档问答，标注本次使用的记忆，纠正记录优先。保持项目资料版本与学习观察分离。

## 第三批：复习调度与教学评测（完成）

以透明规则安排复习，允许用户控制和关闭提醒；读过、模型观察、用户自评与实际练习证据独立。建立不自动调用真实模型的评测案例与运行器，覆盖来源、零基础适配、误区反馈和迁移；实际学习效果仍需真实模型与用户试学。

## 验证

203 项自动测试通过；浏览器使用真实界面、Host 路由与持久化，虚构项目及模拟模型，不代表教学有效性。主使用手册、离线 HTML 和截图同步。

第二批：learning-map.js 校验概念唯一性、前置 DAG、引用范围与推荐来源哈希；功能和概念入口要求明确确认派生的资料清单。地图生成只使用当前选择资料，不扫描全项目或声称实际执行。learning-memory.js 按概念和关键词检索至多 5 条观察及 4 段旧问答；去除历史来源编号、优先用户纠正，并排除已纠正观察所关联的旧反馈。读取旧档案失败会降级为本次不使用旧问答，导出仍保留校验要求；关闭记忆不删除档案。

第三批：learning-review.js 根据逐字有依据的观察安排 1/3 天复习，成功回顾后最长延长到 14 天；规则不是校准过的遗忘或掌握模型。每个概念保持一个当前安排，提醒开关、单主题暂停、推迟和观察纠正均由服务端处理；暂停状态不会被新回答自动解除。提醒由 GET 派生，既有轮询只更新界面，不增加自动模型调用或站外推送。learning-coach 持久化问题上下文，提示不会覆盖原题，课程目录在陪学时收起。

learning-materials 导出增加“学习观察与复习安排.md”，包含纠正、知识关系、来源版本与建议日期；资料包共六份 Markdown、离线 HTML 和清单，不包含源码或运行环境。

teaching-eval.js、scripts/evaluate-teaching.mjs 和 docs/teaching-eval-cases.json 提供 12 个可复用案例（虚构产品与公开维护代码片段）。本地检查协议、引用范围、用户原话和部分风险信号；输出待人工审阅报告，不能证明事实语义成立或用户学会，不读凭据、不调用模型。真实模型回复和真人试学须另外收集。运行方式见 teaching-evaluation.md。

最终验证：203 项测试；真实界面与 Host 路由、虚构项目及模拟模型，验证诊断回答、观察展示、地图确认、复习推迟与开始、资料包 8 项 CRC 校验、桌面和 390px 滚动。截图数据和日期可构造，不冒充真实模型教学结果。每批独立提交，部署保持暂停，未推送远程。
