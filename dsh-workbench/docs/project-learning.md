# 项目陪学：实现与分批记录

初始三批版本：1.21.0。当前教学优化见 [教学架构与分批记录](teaching-architecture.md)，最新操作以主手册为准。三个批次已实现。部署工作保持暂停，当前只修改本地插件，不更新服务器或推送远程。

## 第一批：项目问答与原理导读（完成）

- `learning.js`：有界资料目录、显式选择、只读内容摘录、内容哈希、编号与行号、缺口、零基础讲解提示词及引用范围校验。
- `manager.js`：新增 `learning-sources` / `learn` 操作，独立 `learning.messages` 和资料选择；`kind: learning` 使用现有无工具的 `personal-manager` preset，复用去重、串行锁、停止、重启恢复；完成回复不写入开发消息、不设置执行建议、不改确认状态。
- `client.js`：原管家顶部学习入口、可折叠资料选择、自然提问、导读示例、生活类比、依据展开；每个项目/轮次独立浏览器草稿，学习记录随 manager.json 持久化。
- 导入项目无需交付约定即可学习。资料需要用户主动勾选，默认不上传整个项目；目录及文本预算固定，拒绝隐藏文件、常见凭据路径、符号链接与项目外路径。内容敏感检测只覆盖常见格式，不保证识别所有个人或商业数据。
- 正文中的引用只验证来源编号与行号范围，不验证语义蕴含；来源元数据是该次回答收到的资料清单，不冒充逐句事实核验。旧回答不随代码变化自动更新，下次发送读取新内容并记录新哈希。
- GET 返回学习记录和来源元数据，不返回模型提示词或问答使用的原始源码摘录；用户显式打开的练习副本会作为 editor 文本返回供编辑。待执行的提示词按既有任务机制保存在项目内，完成后清除；备份与访问项目记录时应按私有数据处理。

资料目录最多检查 1,500 个条目、递归深度 4、200 个普通项目文件（另加本轮正式 Markdown）；每次最多 12 份文本，每份不超过 128 KiB，摘录不超过 16,000 字符，总计 48,000 字符。超限、缺失和凭据检测命中进入缺口说明。完整工程理解需要分主题选择资料，不能把一次摘录当作完整项目审计。

## 第二批：学习计划与持续陪学（完成）

目标与基础逐个询问；记录每日可用时间；建立有依据的项目知识地图、可调整课程目录与当前一课；支持复述、轻量测验、复习和问答档案。区分“已阅读”与“已掌握”，不因模型回合完成就标记学会。无来源的内容明确作为通用知识。

## 第三批：实践与完整学习资料（完成，执行边界见下文）

在明确确认后创建选中文件的学习副本，支持编辑和模型反馈，不修改原项目或插件，不执行代码。生成原理导读、个人学习计划、词典与问答记录，支持 Markdown、离线 HTML 与 ZIP。读取资料时比较来源版本，支持用户主动调整课程；联网查找与核验外部学习资源尚未实现。

每批同步更新主使用手册、离线 HTML 和受影响截图，独立验证与提交。后续不应把待实现功能写成可用入口。

## 验证边界

184 项自动测试通过。隔离浏览器使用真实组件、Host 路由和持久化，模拟模型回答；验证未配置交付约定时学习、资料选择、发送、依据展示、恢复、桌面和 390px 布局。未调用真实模型，不代表教学正确性、普通用户学习效果或服务器已更新。

第二批：`learning-plan.js` 校验偏好与结构化课程，服务端拒绝伪造来源、超时长课程和过期计划操作；计划与阅读、自评状态持久化。复述反馈只记录完成时间，不自动改变理解状态；旧计划保留最近 5 份。

第三批：`learning-materials.js` 生成并校验导读和词典，支持 Markdown、无远程资源的离线 HTML 和 ZIP；清单记录计划、资料来源与内容哈希。包不包含编辑器源码或运行环境，也不读取系统模型凭据；用户聊天原文仍在问答档案中。

`learning-practice.js` 需要显式确认才复制所选资料，副本写入本轮 `learning/practices/<id>/files/`；严格按清单定位目标，防止任意路径写入，保存时校验原副本哈希，拒绝常见凭据和过大编辑。反馈仅使用副本摘录，无工具，不修改原项目，不自动执行代码或证明测试通过。副本是选中文件的教学拷贝，不是完整项目或强执行沙箱。当前编辑上限 16,000 字符，较长文件只读展示。

代码更新提示在下一次读取资料时比较计划和资料来源，不持续扫描整个仓库；旧回答、旧计划和旧导出不自动改写。外部链接目前不自动推荐，尚未加入联网检索核验能力。自动运行练习和真实模型教学质量评估另行实施，不能把模拟浏览器旅程作为其验收。

第三批浏览器实测完成：真实组件、Host 路由、持久化和导出文件，虚构项目与模拟模型；资料包 7 个文件 CRC 通过；保存练习后原 README 字节不变，仅副本变化。修复学习页继承简洁模式固定高度造成的内容裁切，桌面和 390px 均可滚动到操作区。最终截图由已验证的虚构状态构造，不能冒充真实模型完成。

长期问答超过 150 条时，将较早部分写入带哈希的本轮 `learning/history/` 档案，页面保留最近 100 条并继续积累；完整问答导出按顺序读取档案并校验，避免长学习周期丢失旧问题。模型提示词仍只携带最近 12 条有限历史。档案读取预算 16 MiB，超限提示管理员分批处理。
