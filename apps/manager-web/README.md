# manager-web（独立产品前端，第一片）

状态：**最小可用，无构建步骤**。设计建议 React + TypeScript + Vite；本仓库离线、无法安装前端工具链，因此先用原生 ES module 实现，保证能直接跑通"登录 → 项目 → 对话 → 回答 → 查看"。

由 `services/product-api` 静态托管（`/`、`/app.js`、`/styles.css`），与 API 同源，因此使用 Cookie 会话 + `x-csrf-token`，没有跨域配置，也没有任何 DSH 凭据或宿主路径。

## 已实现

| 区域 | 行为 |
| --- | --- |
| 登录 | 邮箱 + 密码；展开"我有邀请码"后用邀请码创建账号（`POST /invitations/redeem`） |
| 项目列表 | 读取 `GET /api/v1/projects`，新建项目 |
| 项目内 | 项目详情、互动卡（问题/权限）、消息历史、发送消息（`202` 表示已接收） |
| 互动回答 | 权限卡提供"允许一次/拒绝"，问题卡按题目逐项单选/多选/补充回答，一次提交全部；提交后刷新列表 |
| 我的成果 | 列出 Worker 注册的文档；阅读（Markdown/文本净化显示）、按 hash 确认这一版、下载原文件 |
| 多版本 | 每份成果可切换历史版本（v1/v2…）；历史版本只能阅读与下载，确认只对最新版开放 |
| 实时刷新 | 进入项目即连 SSE（`/api/v1/projects/:id/events`），消息、互动、新成果到达后自动刷新；断线自动重连并显示"正在重连…" |
| 无障碍 | 语义化标签、`aria-live`、可见焦点、窄屏单列 |

## 本地验证

```bash
cd services/product-api
node server.mjs --invite "演示"      # 打印邀请码
node server.mjs                       # 另开一个终端
open http://127.0.0.1:8089/
```

多题问答和取消：SSE 刷新保留同一请求的本地草稿；请求取消或到期后移除。草稿不跨网页关闭持久化。真实本地 Chrome 已验证桌面与 390px，多题提交使用模拟 Worker，没有模型调用。

模拟模式会显示排队/处理中/完成/待核对状态，message_completed SSE 自动刷新模拟回复。真实执行能力仍未接通；截图和试用结果见主使用手册。

完整交互模拟已串联许可→问答→示例文档阅读/明确确认/下载；排队与等待时可取消。状态优先跟随当前活动任务，避免后续排队消息覆盖。无真实模型调用，详见主手册与 simulation-flow.md。

## 对话视觉优化（2026-11-14）

左侧项目导航、中间对话、按需展开的成果侧栏；手机使用“所有项目”导航并可返回对话。输入区固定底部，开场建议仅填入草稿；成果确认、权限审批仍是不同操作。主题跟随系统，支持浅色/深色及减少动画偏好。没有引入构建依赖或外部素材。

本地虚构预览与19项Chrome验证见 [开发者手册](../../dsh-workbench/docs/manager-developer-guide.md)，客户操作与新版截图见 [客户手册](../../dsh-workbench/docs/manager-user-guide.md)。本次没有改动服务器运行版本或调用模型。此前“真实执行尚未接通”的段落为历史阶段描述，最新受限链路和边界以统一Worker文档及服务器验收记录为准。

## 可视化服务控制台

平台管理员从顶部“服务管理”进入概览、额度、任务与 Worker、管理记录四个分区。概览读取管理员专用快照，展示已结算用量、UTC七天图、冻结提醒与 API 进程信息；任务可按名称/账号/编号及状态筛选。操作沿用现有额度与核对接口，不新增远程命令、模型密钥编辑或自动批准能力。普通账号没有入口，服务端请求仍强制拒绝。

当前控制台图文说明、虚构预览命令和权限边界见 [开发者手册](../../dsh-workbench/docs/manager-developer-guide.md)。真实服务器运行版本未切换。

平台管理员现可在“服务管理 → 邀请码”可视化生成一次性邀请，选择独立/已有租户和有效期、复制本次明文并查看使用状态。沿用兑换开关，默认不自动开放注册；不自动分配模型额度或授予平台管理员。操作和限制见开发者手册的邀请码章节。本批仅本机虚构验证，服务器邀请保持关闭。
