# 已有项目测试样本（人工编写，未调用模型）

这是最小静态博客 v0，仅有三篇虚构文章，没有搜索、分类筛选或后台。

必须先复制到测试包生成的独立 workspace，再让业务 Agent 修改。不要把本仓库根目录或此原始 fixture 作为业务工作区。

可用浏览器直接打开 index.html。若用本地 HTTP 服务，只绑定 127.0.0.1，端口由测试人员选择；不安装依赖，不接数据库或外部 API。

正式新增需求：按标题/正文搜索（忽略首尾空格与英文字母大小写）、按分类筛选，可组合使用；无结果显示“没有找到文章”；清空搜索并选择全部后恢复三篇。保留原文章及标题，不改变无关页面。

大小写测试：搜索 ` web ` 或 `WEB` 均应只命中“学习网页制作”；这是正文搜索，同时验证忽略首尾空格和英文字母大小写。基线总数仍为三篇。
